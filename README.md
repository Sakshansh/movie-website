# Lumière — Movie Search & Recommendation Website

A cinematic movie browsing site built with plain HTML, CSS and JavaScript.

## Features
- Featured "Tonight's pick" hero
- Search by title, director, cast, year or plot
- Genre filter chips, sort (rating / newest / oldest / A–Z) and minimum-rating filter
- Favourites list saved in localStorage
- Detail modal with "If you liked this, try…" recommendations
- Generated SVG poster artwork — works fully offline
- Responsive dark UI with film-grain texture

## Run
Open `index.html` in a browser. No build step needed.

## Files
- `index.html` — layout
- `styles.css` — styling
- `movies.js` — sample movie data
- `app.js` — search, filters, favourites, recommendations, poster generator
